## Part 1: 비로그인 상태 테스트

### 1.1 목록 페이지 기본 렌더링

- **결과:** PASS
- **확인 항목:**
  - "질의응답" h1 제목 표시
  - 검색바 ("질문 검색" placeholder)
  - "질문하기" 버튼 (보라색)
  - 탭: 전체보기(활성), 답변완료, 답변 대기중
  - 정렬 버튼 ("최신순") + 필터 버튼
  - 질문 카드 10개 목록 (카테고리 경로, 제목, 미리보기, 답변 수, 조회수, 작성자, 시간)
  - 페이지네이션 (1, 2 페이지 + 이전/다음/처음/마지막)

### 1.2 탭 전환

- **결과:** PASS
- **확인 항목:**
  - "답변완료" 클릭 → URL에 `?answer_status=answered` 반영
  - "답변 대기중" 클릭 → URL에 `?answer_status=unanswered` 반영
  - "전체보기" 복귀 → 파라미터 제거
- **메모:** 탭 전환 시 목록이 즉시 업데이트되며 로딩 상태 표시 정상

### 1.3 검색

- **결과:** PASS
- **확인 항목:**
  - 검색바에 "React" 입력 → 300ms 디바운스 후 URL에 `?search_keyword=React` 반영
  - 검색 결과 없을 때 "'React'에 대한 검색 결과가 없습니다" 빈 상태 메시지 표시
  - 검색어 지우기(X) 버튼 → 원래 목록 복귀
- **메모:** MSW 핸들러에서 키워드 필터링이 구현되어 있지 않아 결과가 0건으로 나옴. 프론트엔드 검색 UI 동작 자체는 정상.

### 1.4 정렬 (SortPopover)

- **결과:** PASS
- **확인 항목:**
  - "최신순" 버튼 클릭 → 팝오버에 "최신순", "오래된순" 옵션 표시
  - "오래된순" 선택 → URL에 `?sort=oldest` 반영
  - 팝오버 외부 클릭 시 닫힘

### 1.5 필터 (CategoryFilterModal)

- **결과:** PASS
- **확인 항목:**
  - "필터" 버튼 클릭 → 카테고리 모달 열림
  - "카테고리 선택" 제목 표시
  - 대분류/중분류/소분류 3단계 드롭다운 표시
  - 중분류/소분류는 상위 선택 전 disabled
  - "선택 초기화" 버튼 + "필터 적용하기" 버튼 (선택 전 disabled)
  - 닫기(X) 버튼 동작

### 1.6 페이지네이션

- **결과:** PASS (부분)
- **확인 항목:**
  - 페이지네이션 UI 정상 렌더링 (첫/이전/1/2/다음/마지막)
  - 2페이지 클릭 시 UI 반응
- **이슈:** 2페이지 클릭 시 URL에 `page=2` 파라미터가 반영되지 않는 것으로 보임. MSW 데이터 한계로 동일 데이터 반환.

### 1.7 질문 상세 진입

- **결과:** PASS
- **확인 항목:**
  - 첫 번째 질문 카드 클릭 → `/qna/1` 경로 이동
  - 브레드크럼 표시 (프론트엔드 > 프로그래밍 언어 > Python)
  - 질문 제목, 조회수, 작성자 아바타 표시
  - "1개의 답변이 있어요" 답변 섹션 확인
  - 뒤로가기 → 목록 복귀
- **이슈 (MSW 한정):** 목록의 제목과 상세 페이지 제목이 다름. MSW 핸들러가 question_id와 무관하게 동일 더미 데이터를 반환하기 때문. 프론트엔드 로직은 정상.

## 발견된 이슈

### 이슈 1: 페이지네이션 URL 파라미터 (1.6)

- **심각도:** LOW
- **설명:** 2페이지 클릭 시 UI 반응은 있으나 URL에 `page=2` 파라미터 미반영 가능성
- **영향:** 새로고침 시 2페이지 상태 유지 안 될 수 있음
- **원인 추정:** MSW 환경에서의 데이터 한계 또는 handlePageChange 로직 확인 필요

### 이슈 2: MSW 상세 데이터 불일치 (1.7)

- **심각도:** NONE (MSW 한정)
- **설명:** 목록의 질문 제목과 상세 페이지 제목이 다름
- **원인:** MSW 핸들러가 question_id와 무관하게 동일 더미 데이터 반환
- **영향:** 프론트엔드 로직에는 문제 없음. 실제 백엔드 연동 시 자동 해소

### 이슈 3: MSW 검색 미구현 (1.3)

- **심각도:** NONE (MSW 한정)
- **설명:** "React" 검색 시 결과 0건 — MSW에서 키워드 필터링 미구현
- **영향:** 검색 UI 동작 자체는 정상. 빈 상태 메시지도 정상 표시
